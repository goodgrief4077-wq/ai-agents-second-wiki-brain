# skills

Agent-neutral skills for AI coding agents (Claude Code, opencode, pi, omp, Codex, hermes). Each folder holds one `SKILL.md`.

These are sanitized copies of private working skills: machine paths, vault names and personal project tables are replaced by `<placeholders>` or `~`. Fill them in for your own setup. They are instructions for agents, not wiki pages: no lint rules for `wiki/` or `raw/` apply.
