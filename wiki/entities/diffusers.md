Diffusers is Hugging Face's Python library for running and building diffusion models for image, audio and 3D generation.

## What it does
The README describes Diffusers as the library for pretrained diffusion models for images, audio and 3D structures of molecules, designed for usability over performance, simple over easy and customizability over abstractions. It has three core components: diffusion pipelines that run inference in a few lines, interchangeable noise schedulers, and pretrained models as building blocks. It installs with pip or a community-maintained conda package. The quickstart loads a pretrained pipeline with from_pretrained, naming a Stable Diffusion v1.5 checkpoint, and says the Hub has 30,000+ checkpoints. It also has a Modular Diffusers path and an optimization guide.
