Unsloth is a desktop app and library for running and fine-tuning open models locally, with launchers for several coding agents.

## What it does
The README describes Unsloth as a desktop app to run and train models, available as Unsloth Desktop, Unsloth Studio (web UI) and Unsloth Core (code). It lists running and training LLMs, GGUF, diffusion, embedding and audio models; using local models with Claude Code, Codex and MCP; web search and RAG; serving an OpenAI-compatible API; and access over LAN or through a Cloudflare HTTPS link. For training it claims 2x faster fine-tuning with 70% less VRAM with no accuracy loss, and lists LoRA, QLoRA, full fine-tuning, pretraining, RL, GRPO, DPO and FP8, with export to formats such as GGUF. A start command connects coding agents (Claude Code, Codex, Hermes Agent, OpenCode, OpenClaw and others) to local models. Install is by app download, script, Homebrew or Docker.
