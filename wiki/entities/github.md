GitHub is a hosted platform for building software, based on Git, that adds repository hosting, planning, review, automation and security tools.

## What it does
The "What is GitHub?" docs page describes GitHub as a platform covering the whole software development life cycle: plan (issues, milestones), create (write and store code), review (pull requests), test (automated checks), deploy (automated workflows and releases) and operate (monitoring, dependencies, security fixes). It says GitHub builds on the open-source Git version control system by hosting repositories in the cloud and adding collaboration tools. Listed uses include code storage, collaboration, open-source contribution, project tracking, CI/CD automation, package publishing, hosting documentation and sites, and AI-powered tools and agents.

## Limits
GitHub is a hosted service with no single version, so tool_version is `hosted-service`. This page covers only the overview docs page; pricing, plans, Actions, Copilot and security products are not described here.
