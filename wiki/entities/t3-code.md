T3 Code is a web, desktop and mobile control surface for coding agents that are already set up on your computer.

## What it does
The README calls T3 Code an agent harness control surface with a mobile app (iOS, Android), a web app and an Electron-based desktop app. It works with your existing subscriptions on Claude Code, Codex, Cursor, Grok Build, OpenCode and Google Antigravity; at least one provider must be installed and signed in first. The `t3` command starts the server and opens the local web app, with subcommands to run as a background service and to update. The desktop app is available from GitHub Releases, winget, scoop, Homebrew, a .deb package or AUR. The docs folder covers permission modes, remote access from a phone or another machine, and connecting Claude Code, Codex and other agents over MCP. Building from source uses the Vite+ `vp` tool.

## Limits
Version taken from the GitHub releases page on 2026-10-11. The README says the project is very early, expect bugs, and that big feature contributions are not accepted. There is no docs site, only a docs/ folder. This page covers the repository front page and README only.
