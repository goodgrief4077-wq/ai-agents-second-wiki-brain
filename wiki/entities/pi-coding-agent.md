A minimal, extensible agent harness (earendil-works/pi, MIT) for coding with LLMs.

## What it does
Customised through extensions, skills, prompt templates and themes, shareable as packages. Runs interactively, in print or JSON mode, over RPC, or through a TypeScript SDK. The monorepo also ships a unified multi-provider LLM API package.

## Limits
Skips features such as sub-agents and plan mode; users add them. Needs Node.js 22.19 or newer. The README states new contributors' issues and PRs are auto-closed by default. Version taken from the GitHub releases page on 2026-10-11.
