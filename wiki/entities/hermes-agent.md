Hermes Agent is an open-source agent from Nous Research (MIT), described in its README as the self-improving AI agent with a built-in learning loop.

## What it does
The README lists CLI commands for setup, update and diagnosis (`hermes setup`, `hermes update`, `hermes doctor`) and links a page labelled Hermes Desktop. The repository tree has providers, plugins, skills and optional MCP folders.

## Limits
A `hermes claw migrate` command exists for users coming from OpenClaw. Version taken from the GitHub releases page on 2026-10-11.
