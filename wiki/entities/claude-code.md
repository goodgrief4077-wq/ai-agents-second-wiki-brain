Claude Code is Anthropic's agentic coding tool for the terminal, described on its GitHub front page.

## What it does
The README describes an agentic coding tool that lives in your terminal, understands your codebase, and handles routine tasks, code explanation and git workflows through natural language. It can be used in the terminal, in an IDE, or by tagging @claude on GitHub. Recommended installs are a script for macOS/Linux, Homebrew, a script for Windows, and WinGet; the npm install is marked deprecated. The repository includes several plugins that add custom commands and agents. Bugs are reported with the /bug command or a GitHub issue. The README has a data-collection section: feedback, usage data (such as code acceptance or rejection), related conversation data and /bug feedback are collected, with stated safeguards of limited retention, restricted access to session data, and a policy against using feedback for model training.
