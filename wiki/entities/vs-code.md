Visual Studio Code is Microsoft's code editor, developed in the open as the MIT-licensed Code - OSS repository and shipped as a Microsoft-licensed distribution.

## What it does
The microsoft/vscode README says Microsoft develops the product in that repository with the community, under the MIT licence. It describes Visual Studio Code as combining a simple code editor with editing, navigation, understanding, lightweight debugging, an extensibility model and integration with existing tools, updated monthly, for Windows, macOS and Linux. The docs landing page lists sections on agents, agent customization, models, MCP, hooks, plugins, extensions, settings and troubleshooting, and offers llms.txt and Markdown versions of articles.

## Limits
Version taken from the GitHub releases page on 2026-10-12. The README says the downloadable Visual Studio Code is a distribution with Microsoft-specific customizations under a separate Microsoft product licence, so the MIT licence covers the Code - OSS source, not necessarily the shipped binary. This page covers the repository front page and docs landing page only.
