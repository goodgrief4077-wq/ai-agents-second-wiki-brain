ComfyUI is a node-graph application and engine for running generative image, video, audio and 3D models locally, with an API and a cloud option.

## What it does
The README describes ComfyUI as a modular AI creation engine with a node graph interface for generating images, video, 3D models and audio. It claims to be an optimized diffusion-model inference engine for consumer hardware and says it can run large models on as little as 4GB VRAM with 8GB RAM through asynchronous weight streaming. It runs on Windows, Linux and macOS via a desktop app (Windows and macOS), a portable install or a manual install, with a paid Comfy Cloud. Features listed: reusable subgraphs, templates, an App Mode, a local API, asynchronous queueing, partial graph re-execution and VRAM management. It lists native support for many image, editing, video, audio, 3D and text models, and partner nodes that call closed-source models.
