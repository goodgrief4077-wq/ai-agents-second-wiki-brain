Model Context Protocol (MCP) is a protocol; this repository holds its specification, protocol schema and official documentation.

## What it does
The repository contains the MCP specification, the protocol schema and the official MCP documentation. The schema is defined in TypeScript first and also published as JSON Schema.

## Limits
Releases are dated rather than numbered; the latest on the GitHub releases page on 2026-10-12 is 2026-07-28. This page covers the repository's front page only, not the specification text. The LICENSE file says the project is moving from the MIT licence to Apache-2.0: new code and specification contributions are Apache-2.0, documentation other than specifications is CC-BY-4.0, and older contributions without relicensing consent stay MIT; GitHub reports no single licence.
