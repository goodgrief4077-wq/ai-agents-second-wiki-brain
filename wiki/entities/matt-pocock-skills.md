Matt Pocock Skills is a public collection of agent skills for day-to-day engineering work, installable into several coding agents.

## What it does
The README describes a set of small, composable agent skills the author uses daily, positioned against process-owning approaches (it names GSD, BMAD and Spec-Kit). Install paths: a plugin for Claude Code, Codex and GitHub Copilot that updates itself, a manual install for Gemini CLI, and a skills.sh copy-into-project route for other agents. A setup skill is run once per repo to configure the issue tracker, triage labels and doc locations. Failure modes it targets: misalignment (answered by grilling-session skills), verbosity (a shared glossary), and code that does not work (small feedback steps). Engineering skills listed include grill-with-docs, triage, to-spec, to-tickets, implement, implement-spec, wayfinder, retro, tdd, diagnosing-bugs, research, code-review, pr and wizard. Productivity skills include grill-me, handoff, teach, wait-what and writing-for-agents.
