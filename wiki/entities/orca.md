Orca is a desktop and mobile app for running a fleet of coding agents in parallel, each in an isolated git worktree.

## What it does
The README describes Orca as an AI orchestrator that runs agents such as Codex, Claude Code, OpenCode or Pi side by side, each in its own git worktree, tracked in one place. Features listed: parallel worktrees, terminal splits, a Design Mode that sends a clicked UI element's HTML, CSS and screenshot into an agent prompt, GitHub and Linear integration, SSH worktrees for remote machines, diff annotation, a CLI that agents can drive, quick open, account switching with usage tracking, repo previews, Computer Use, and notifications. A mobile companion for iOS and Android pairs with the desktop app to monitor and steer agents. It says it works with any CLI agent that runs in a terminal and lists many by name. Install is by download, Homebrew cask or an AUR package. The README points to privacy and telemetry docs for the anonymous usage data it collects and how to opt out. The relay that pairs the mobile app with a desktop host is in the same repository under cloud/.
