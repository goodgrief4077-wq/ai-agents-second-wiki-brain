Remotion is a React-based framework for creating and rendering videos with code, under a special licence.

## What it does
The README describes Remotion as video tools for the agent era: making videos agentically with a coding agent, interactively with drag and drop, or programmatically from data and code, with React code as the source of truth. Under video automation it lists design systems (a library of animated assets for an organisation), batch rendering on your own infrastructure, and applications, from a simple tool to a video editor. Getting started is a create-video command from Node.js. The README points to more than 1000 documentation pages covering agent skills, prompts, templates, rendering with Node.js APIs, Lambda and Vercel, the Player and an editor starter.

## Limits
Version taken from the GitHub releases page on 2026-10-12. The README says Remotion has a special licence and may need a company licence; read the LICENSE page before commercial use. GitHub reports no standard licence. This page covers the repository front page and README only. The LICENSE file describes two tiers: free for individuals and small companies, and a company licence required for for-profit organisations of a certain size; it notes the terms change in Remotion 5.0.
