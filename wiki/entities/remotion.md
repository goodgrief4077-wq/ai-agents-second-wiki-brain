Remotion is a React-based framework for creating and rendering videos with code, under a special licence.

## What it does
The README describes Remotion as video tools for the agent era: making videos agentically with a coding agent, interactively with drag and drop, or programmatically from data and code, with React code as the source of truth. Automation uses listed are design systems of animated assets, batch rendering on your own infrastructure, and applications such as editors. Getting started is a create-video command from Node.js. The README points to more than 1000 documentation pages covering agent skills, prompts, templates, rendering with Node.js APIs, Lambda and Vercel, the Player and an editor starter.
