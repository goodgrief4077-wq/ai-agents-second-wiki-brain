GitHub front page for the repository behind mpp.dev, the documentation site for the Machine Payments Protocol (MPP), an open standard for machine-to-machine payments co-authored by Tempo and Stripe. It holds docs, protocol explainers, SDK references and a directory of live MPP services; the SDKs live in separate repositories.
