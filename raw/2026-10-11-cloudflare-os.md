GitHub front page for Cloudflare OS, an agent workspace on Cloudflare Workers that Cloudflare uses internally and has open-sourced as a base for a company's own AI productivity environment. It has an agent chat UI, sandboxed per-user apps called gadgets, and a capability-based security layer called Gatekeepers.
