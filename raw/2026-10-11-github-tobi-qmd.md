GitHub landing page of qmd ("Query Markup Documents"). The README describes an on-device search engine for markdown notes and documents that combines BM25 full-text search, vector search and LLM re-ranking, run locally through node-llama-cpp with GGUF models. It documents collections, per-collection context strings, an embed step, search, vector-search and hybrid query commands, JSON and file-list output for agents, and an MCP server exposing query, get, multi-get, status and metadata tools.
