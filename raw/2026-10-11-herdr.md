GitHub front page for herdr, a Rust terminal multiplexer and runtime for coding agents. It keeps terminals running in a background server, shows each pane as working, blocked or idle, and lets agents drive it through a CLI and socket API. The README lists install methods and the Apache-2.0 licence.
