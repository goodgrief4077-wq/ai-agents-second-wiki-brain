GitHub front page for GBrain by Garry Tan, a memory layer for AI agents that stores facts with sources and exposes them across agents, including over MCP. It offers keyword retrieval without keys, optional semantic search, synthesis and a typed knowledge graph. The README also warns that the npm package named gbrain is unrelated.
