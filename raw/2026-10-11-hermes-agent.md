Hermes Agent is an open-source AI agent framework from Nous Research described as "the agent that grows with you." The README lists CLI commands for setup, update and diagnosis and links a page labelled Hermes Desktop. The repository tree has providers, plugins, skills and optional MCP folders, and a migrate command exists for users coming from OpenClaw.
