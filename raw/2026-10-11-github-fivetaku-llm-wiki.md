GitHub landing page of fivetaku/llm-wiki, a Korean-language starter workspace for Claude Code that implements the Karpathy LLM Wiki pattern. The README describes four layers (inbox, immutable raw, LLM-written wiki, schema) with numbered folders, slash commands for ingest, compile, query and lint, and an index that acts as a router using canonical names (aliases) and size-based sharding instead of a flat catalogue. Query answers are filed back into a queries folder. It claims no dependency on external skills or plugins and presents itself as a starting point, not a final answer.
